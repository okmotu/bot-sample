# Бот для Айыл Өкмөтү

Node.js-клиент для создания игровых агентов. Подключается к месту игрока, получает состояние партии и выбирает действие. Поддерживает три способа управления:

| Режим | Кто выбирает ход | Запуск |
|---|---|---|
| Стратегия | Ваш JavaScript-код | `npm start` |
| LLM | Модель через совместимый с OpenAI Chat Completions API | `npm start` с `LLM_MODEL` |
| MCP | Внешний агент, вызывающий инструменты игры | MCP-клиент → `src/cli/mcp.mjs` |

Сервер рассчитывает выплаты, бросает кубики и проверяет действия. Этот репозиторий содержит клиент, а не движок игры.

## Быстрый запуск

Требуется Node.js 26.4 или новее. Для TUI используется экспериментальный FFI; нужный флаг уже включён в команды ниже.

```bash
git clone https://github.com/okmotu/bot-sample.git
cd bot-sample
npm ci
npm start
```

В лобби игры нажмите **Передать место боту** и вставьте полученную ссылку в форму подключения. После подключения организатор запускает партию. Без настройки LLM работает стратегия из [`src/strategies/baseline.mjs`](src/strategies/baseline.mjs).

Приглашение одноразовое, действует 10 минут и выдаёт доступ только к своему месту в одной партии. Подключение сохраняется в `.aiyl-session.json` в корне репозитория. После остановки через `Ctrl+C` повторный `npm start` продолжит игру. Завершение партии или **Играть самому** в интерфейсе отзывает доступ.

Для нескольких ботов используйте отдельную копию репозитория и приглашение на каждое место.

## Терминальная панель

```bash
npm start
```

`npm start` открывает терминальную панель и загружает `.env`. Для просмотра без ключа и без подключения к игре:

```bash
npm run demo
```

Лента группирует решения по ходу: бросок, переброс, торги и покупка одного хода находятся вместе. Заголовок хода сворачивается мышью или клавишей Space. Дополнительные ходы и торги во время чужого хода различаются по серверным данным.

У каждого решения видны выбранное действие, краткое объяснение, ближайшая альтернатива, источник (модель или JavaScript-стратегия), статус отправки и стоимость запроса. Объяснение и альтернатива приходят от модели; стратегия без LLM не выдаётся за рассуждение модели.

Кнопки под решением раскрывают исторический снимок:

- **Стол:** предприятия, достопримечательности и баланс всех игроков.
- **Рынок:** все доступные виды, цвета, числа активации, цены и количество; возможность покупки на тот момент.
- **Отладка:** допустимые действия, вход JSON, системный промпт и расход токенов.

Мышь открывает разделы и прокручивает ленту. `↑↓` — выбрать решение, `1/2/3` — стол/рынок/отладка, `d` — следующий раздел отладки, `Home/End` — начало/конец истории, `f` — к последнему, `e` — экспорт, `q` или `Ctrl+C` — выход. Новые события не сбрасывают просмотр старого снимка. Демо содержит 6 игроков, 12 видов на рынке и 26 решений.

Если сохранённой сессии нет, `npm start` показывает форму приглашения внутри терминала. Ссылка маскируется и не попадает в ленту. После подключения бот начинает ждать своего хода. Панель остаётся открытой после окончания партии или ошибки. Автоматической памяти стратегии и обучения на журнале здесь нет. Подсказки тренера сохраняются на время текущего запуска.

История хранится в памяти до выхода. Экспорт создаёт новый `bot-decisions-*.json` в текущей папке с правами `0600`; файлы исключены из Git. Он может содержать собственный тайный выбор бота, поэтому предназначен для локального просмотра. Ключ модели, токен подключения, приглашение, заголовки запросов и тела ошибок не записываются; известные секреты и терминальные управляющие символы скрываются также в тексте объяснения. Поле `reason` — краткое обоснование модели, не её внутренние рассуждения. JavaScript-стратегия объяснение не генерирует.

«Ход принят» означает успешный ответ сервера. HTTP 409 означает отказ из-за смены версии: бот перечитает состояние. При потере ответа результат отмечается как неизвестный. Следующее наблюдение может включать действия соперников и не выдаётся за последствия только этого хода.

Токены входа, выхода, кеша и стоимость берутся из ответа провайдера. Неизвестные значения помечаются `н/д`; сумма расходов показывает только известную стоимость, включая запросы перед отклонёнными действиями. Данные демонстрации вымышленные, платных запросов нет. Для запуска требуется интерактивный терминал.

## Чат тренера

Кнопка **«c Тренер»** или клавиша `c` открывает приватный чат с LLM-ботом. Напишите, например: «Не покупай больше Мал. Копи на Хан-Сарай». `Enter` отправляет подсказку, `Esc` возвращает в ленту. Ввод текста не запускает горячие клавиши ленты; чат прокручивается мышью и Page Up/Down.

Подсказки попадают в **следующий запрос модели** и остаются активными до отмены кнопкой у сообщения или завершения партии. Новая подсказка не прерывает уже выполняющийся запрос. Модель отвечает в объяснении следующего действия: как учла совет или почему предпочла другой ход. Отдельного запроса и оплаты за ответ в чате нет, но активные подсказки увеличивают входной контекст каждого решения.

В чате видно, в какое решение передана подсказка. Это подтверждение доставки в запрос, а не гарантия, что модель ей последовала. У решения кнопка **«4 Советы»** показывает точный снимок подсказок на тот момент, даже если позже их отменили. При конфликте советов модель ориентируется на более новый; правила и допустимые действия остаются обязательными.

Чат работает только с настроенной LLM, не с JavaScript-стратегией или внешним MCP-агентом. Сообщения не передаются игровому серверу и соперникам: они идут вашему провайдеру LLM вместе с позицией. Хранятся в памяти до выхода и входят в ручной экспорт журнала. После перезапуска их нужно ввести заново. Лимит — 20 активных подсказок по 1000 символов.

В `npm run demo` можно отправлять и отменять подсказки; ответ демонстрационный, без сетевых запросов.

## Подключение LLM

```bash
cp .env.example .env
```

Заполните `.env`. Например, для OpenRouter:

```dotenv
LLM_MODEL=openai/gpt-5.4-mini
LLM_API_KEY=ваш_ключ
LLM_BASE_URL=https://openrouter.ai/api/v1/
```

Запустите `npm start`. Команда загружает `.env`; файл и сохранённая сессия исключены из Git.

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `LLM_MODEL` | ID модели у провайдера | Не задана: используется JavaScript-стратегия |
| `LLM_API_KEY` | Ключ выбранного провайдера | Обязателен в режиме LLM |
| `LLM_BASE_URL` | Базовый URL Chat Completions API | `https://api.openai.com/v1/` |

### Публичная подпись бота

По умолчанию другие игроки видят в подсказке значка бота `bot-sample · <LLM_MODEL>`. Без LLM показывается только `bot-sample`. Эти названия передаёт сам бот; игра их не проверяет.

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `BOT_METADATA` | `false` отключает обе подписи | Включено |
| `BOT_HARNESS` | Название вашего харнесса; пустая строка скрывает его | `bot-sample` |
| `BOT_MODEL` | Публичное название модели; пустая строка скрывает его | Значение `LLM_MODEL` |

Подпись отправляется при подключении и обновляется при запуске с сохранённой сессией, включая TUI. Измените `.env` и перезапустите процесс; отключение уберёт и ранее опубликованные значения. Ключи и адрес провайдера не отправляются. На сервере без поддержки метаданных бот продолжает играть без подписи.

Для внешнего MCP-агента модель неизвестна: задайте `BOT_MODEL` явно в окружении MCP-процесса. `npm run mcp` и `npm start` загружают `.env`; при прямом запуске `node src/cli/mcp.mjs` передайте переменные через настройки MCP-клиента или флаг Node `--env-file` с абсолютным путём. Чтение через MCP-инструмент `game_state` остаётся без побочных изменений; подпись синхронизируется перед запуском MCP-сервера.

Модель должна поддерживать строгий `response_format: json_schema`. Один выбор действия вызывает один запрос к модели с лимитом ответа 500 токенов и таймаутом 45 секунд. Сетевая ошибка или некорректный ответ модели останавливают агента без автоматического повторного запроса.

## Как выполняется ход

1. Клиент читает состояние своего места: `game`, `catalog`, `landmarks`, `actions`, `version` и `gameNumber`.
2. Если `actions` пуст, агент ждёт. Иначе стратегия или LLM выбирает индекс из этого массива.
3. Клиент отправляет `actionIndex` вместе с прочитанными `version` и `gameNumber`.
4. Сервер проверяет действие и сохраняет результат. Если состояние успело измениться (`409`), агент читает его заново и выбирает новый ход.

Между обычными итерациями — пауза 2 секунды. Ошибки связи с игровым API повторяются до пяти раз подряд; завершённый или отозванный доступ (`401`/`404`) останавливает цикл и удаляет локальную сессию.

### Что получает модель

Запрос формируется в [`src/strategies/llm.mjs`](src/strategies/llm.mjs):

- **Системное сообщение** — инструкция из [`src/prompts/system.mjs`](src/prompts/system.mjs), включающая памятку [`src/prompts/rules.mjs`](src/prompts/rules.mjs).
- **Пользовательское сообщение** — JSON из `modelInput(state)`: своё публичное представление партии, каталог без иллюстраций, достопримечательности, последние 12 строк хроники и действия с явными индексами.

Ключи API, приглашение и токен игрового доступа в запрос не включаются. Тайные решения соперников отфильтровывает сервер игры.

Модель возвращает:

```json
{
  "actionIndex": 2,
  "alternativeIndex": 4,
  "reason": "Молочный цех вместо ещё одного Мала: три Мала уже дают ему ресурс."
}
```

Клиент проверяет индекс перед отправкой хода. `alternativeIndex` обозначает другое доступное действие; при единственном варианте это `null`. Некорректная альтернатива не показывается. `reason` доступен через обработчик `onDecision` функции `chooseWithModel` и в локальной TUI; он не публикуется в игре. Обмен репликами между ботами в режиме LLM не реализован — этот пример только выбирает действия.

## Структура проекта

```text
src/
  cli/
    play.mjs          # игровой цикл: npm start
    mcp.mjs           # запуск MCP через stdio
  observer/
    journal.mjs      # снимки решений, результаты, расход, безопасный экспорт
    tui.mjs          # лента решений OpenTUI
    turns.mjs        # группировка решений по серверному ходу
    connect.mjs      # форма подключения внутри TUI
    views.mjs        # представление действий и состояния
    demo.mjs         # вымышленные данные, без сетевых запросов
  game/
    run.mjs          # общий цикл для TUI и обычного запуска
    client.mjs        # HTTP-клиент игры
    metadata.mjs      # публичные harness/model и синхронизация подписи
    session.mjs       # приглашение и файл доступа
  strategies/
    baseline.mjs      # стратегия без LLM
    llm.mjs           # подготовка запроса и проверка ответа модели
  prompts/
    system.mjs        # системная инструкция модели
    rules.mjs         # памятка правил, включаемая в инструкцию
  mcp/
    server.mjs        # определения инструментов MCP
tests/               # проверки API-клиента, LLM, MCP, CLI и сессии
```

### Изменение поведения бота

**Своя стратегия.** Измените `chooseAction(state)` в `src/strategies/baseline.mjs`. Она должна вернуть индекс действия из `state.actions`. Например, этот фрагмент выбирает покупку Арпы, если сервер её разрешает:

```js
const index = state.actions.findIndex(
  action => action.type === 'buy' && action.card === 'wheat',
);
if (index >= 0) return index;
// Для остальных ситуаций оставьте выбор другого допустимого действия.
```

**Свой промпт.** Измените `src/prompts/system.mjs`. Памятка правил подключается из `src/prompts/rules.mjs`; цены и эффекты карт приходят из серверного каталога. Состав данных, отправляемых модели, задаёт `modelInput` в `src/strategies/llm.mjs`.

## Подключение внешнего агента через MCP

Сначала сохраните подключение через форму TUI, не запуская игровую стратегию:

```bash
npm start -- --connect-only
```

После сохранения форма закроется; бот не будет делать ходы самостоятельно. Добавьте stdio-сервер в настройки MCP-клиента. Укажите абсолютный путь к своей копии репозитория:

```json
{
  "mcpServers": {
    "aiyl": {
      "command": "node",
      "args": ["/absolute/path/bot-sample/src/cli/mcp.mjs"]
    }
  }
}
```

Если ранее был указан корневой `mcp.mjs`, замените путь на `src/cli/mcp.mjs`. Файл сессии остаётся в корне репозитория и не зависит от рабочей папки MCP-клиента.

| Инструмент | Назначение |
|---|---|
| `game_state` | Прочитать состояние, версию и доступные действия |
| `game_action` | Выполнить действие по индексу с актуальными `version` и `gameNumber` |
| `trade_message` | Отправить реплику участникам торгов Автоимпорта; тайный выбор выполняется отдельно через `game_action` |

Для `trade_message` повторяйте тот же `messageId` при повторной отправке, чтобы избежать дубликатов. При пустом списке действий внешний агент должен ждать; MCP сам не запускает игровой цикл. Не запускайте одновременно `npm start` и внешний агент для одного места.

## Тесты

```bash
npm test
```

Проверяются передача приглашения, запросы модели, MCP handshake, сохранение сессии после переноса файлов и отказ запуска без терминала, режим подключения без ходов и остановка цикла при ошибке LLM. Тесты подменяют сетевые обращения и не вызывают платные модели.

Проверки панели: `npm test` проверяет игровой цикл и журнал; `npm run test:tui` — рендер, клавиатуру и изменение размера терминала под Node.js 26.4+ с FFI.
